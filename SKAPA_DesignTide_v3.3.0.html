국립해양조사원 조화상수 OpenAPI 인증키 안내

  1. 바다누리 해양정보 서비스에 로그인합니다.
  2. 조위관측소 조화상수 OpenAPI를 신청하고 인증키를 발급받습니다.
  3. 발급된 인증키를 국립해양조사원 OpenAPI 인증키 · DT 계열 입력란에 저장합니다.
  4. 이 인증키는 DT 계열 조위관측소의 M₂·S₂·K₁·O₁ 조화상수 조회에만 사용합니다.
  5. 새 인증키를 저장하면 이 PC에 저장된 기존 인증키는 삭제되고 새 키로 교체됩니다.
조위관측소 조화상수 API 안내열기 ↗ 바다누리 API 인증키 발급·관리열기 ↗

적용 범위: DT 계열 조위관측소 조화상수 조회 전용

타이드베드 조화상수 Decoding 인증키 안내

  1. 공공데이터포털에 로그인합니다.
  2. 예측조위(타이드베드) 기준항 조화상수 자료에 활용신청을 완료합니다.
  3. 마이페이지의 인증키 목록에서 일반 인증키(Decoding)를 복사합니다.
  4. Encoding 인증키가 아닌 Decoding 인증키를 SKAPA의 타이드베드 입력란에 저장합니다.
  5. 이 인증키는 강양항 등 타이드베드 관측소의 M₂·S₂·K₁·O₁ 조화상수 조회에만 사용합니다.
